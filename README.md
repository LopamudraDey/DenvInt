# DenvInt
DenvInt: A database of protein–protein interactions between dengue virus and its hosts

• Total Interactions: Contains 784 unique manually curated protein-protein interactions.
• Host Breakdown: Features 535 dengue-human interactions (across 335 human proteins) and 249 dengue-mosquito interactions (across 140 mosquito proteins).
• Viral Proteins Covered: Covers all 10 proteins encoded by the dengue genome (C, E, PrM/M, NS1, NS2A, NS2B, NS3, NS4A, NS4B, and NS5)
